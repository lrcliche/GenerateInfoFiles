1. LO APRENDIDO DURANTE EL DESARROLLO DEL PROYECTO
Durante este proceso, logré consolidar el uso de la Programación Orientada a Objetos (POO) en Java 8,en la gestión de datos masivos. Aprendí a utilizar estructuras de datos avanzadas como HashMap para optimizar búsquedas y procesar archivos planos (CSV) de forma automática. También fortalecí mis habilidades en la automatización de procesos, pasando de la generación de datos pseudoaleatorios a la consolidación de reportes de ventas complejos sin intervención del usuario.

2. POSIBLES APLICACIONES PROFESIONALES
Como futuros Ingenieros de Software, las destrezas adquiridas en el manejo de archivos I/O (entrada/salida) y la generación de reportes automáticos son fundamentales para el desarrollo de sistemas ERP, software de facturación o herramientas de análisis de datos. La capacidad de estructurar un código bajo estándares de documentación (JavaDoc) y buenas prácticas de nombramiento me prepara para trabajar en entornos de desarrollo profesionales y colaborativos.

3. DIFICULTADES PRESENTADAS
La principal dificultad fue la orquestación del flujo de datos: asegurar que los archivos generados por la clase 'GenerateInfoFiles' fueran leídos y procesados correctamente por la clase 'main'; Además, el reto de implementar algoritmos de ordenamiento descendente (de mayor a menor) para los reportes finales requirió un estudio profundo sobre las colecciones en Java y el manejo de excepciones para garantizar que el programa no falle ante archivos con formatos inconsistentes.
